# ФБЛ Team Navigator

Адаптивный интерфейс внутренней платформы фонда: температура команды, признание вклада, благодарности и банк идей.

## Состав

- `index.html` — страница со встроенными стилями и JavaScript.
- `hr-hub-local/fonts/` — локальные шрифты TT Fors из HR-хаба.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

Сборка и установка зависимостей не требуются. Пути к шрифтам относительные: страница работает и в корне домена, и в подпапке репозитория.

## Локальный запуск

Откройте `index.html` в браузере. Или запустите в папке проекта:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Загрузка на GitHub

1. Распакуйте архив.
2. Загрузите содержимое папки в корень репозитория: `index.html` должен лежать непосредственно в корне.
3. Сохраните изменения в основной ветке.

Для публикации через GitHub Pages выберите в настройках репозитория раздел Pages, публикацию из ветки (`Deploy from a branch`), основную ветку и папку `/ (root)`. Сохраните настройки. Адрес опубликованной страницы будет показан в разделе Pages.

## Текущее состояние

Это интерактивный прототип интерфейса. Числа, сотрудники и записи заданы в HTML.

- Меню прокручивает страницу к разделам.
- Модальные окна открываются и закрываются.
- Формы проверяют обязательные поля и показывают уведомление; данные не отправляются на сервер и не сохраняются.
- Реакции и поддержка идей меняются только до перезагрузки страницы.
- Кнопка профиля показывает уведомление; отдельный профиль ещё не реализован.

Авторизация, база данных, обработка обращений, разграничение доступа и гарантии анонимности требуют отдельной серверной реализации. Описания этих процессов в интерфейсе отражают проектируемое поведение.

## Редактирование

Разметка, стили и логика находятся в `index.html`. Шрифты подключены через `@font-face` в начале файла.

Лицензия на свободное распространение проекта не назначена. TT Fors и фирменные материалы включены из существующего проекта; условия их использования и распространения определяются правообладателями. Архив содержит имена и тексты из текущей версии страницы.
